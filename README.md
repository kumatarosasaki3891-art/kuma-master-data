# kuma-master-data

**佐々木熊太郎**が公開しているアプリ群（🐧簡単コンテナ管理、🦅簡単サービス診断、🐯簡単配当日記 など）のための、読み取り専用マスターデータ（JSON）リポジトリです。

## 設計原則

- **秘密情報なし・完全公開**：このリポジトリには API キーや個人情報、ユーザー環境データは一切含まれません。
- **人間のレビュー必須**：GitHub Actions による定期更新は直接 `main` ブランチへコミットせず、Pull Request を作成します。管理者が差分を確認してからマージします。
- **完全ローカル照合**：各アプリは起動時（1日1回まで）または手動更新時に自分のドメインの JSON と `apps.json` のみを取得し、端末内のローカル SQLite に保存してオフラインでも診断・照合を行います。
- **ユーザーデータ非送信**：アプリ側からユーザー環境情報や診断結果を外部へ送信することはありません。

## ディレクトリ構成

```text
kuma-master-data/
├── apps.json                # 各アプリの最新安定版バージョン定義
├── penguin/
│   ├── engines.json         # Docker / Podman / nerdctl の最新版・リリース履歴
│   ├── runtimes.json        # コンテナ内・ローカルランタイムのブランチ別 EOL / 最新パッチ / 緊急 advisory
│   └── README.md            # 情報源・更新方針・緊急 advisory の手動追加手順
├── dividend/
│   ├── dividends.json       # 配当情報（🐯簡単配当日記用・準備中）
│   └── README.md
├── scripts/
│   └── update_penguin.py    # 定期更新用スクリプト（Python 標準ライブラリのみ）
└── .github/workflows/
    └── update-penguin.yml   # 週次自動更新ワークフロー（PR 作成）
```

## スキーマ共通ルール

すべての JSON ファイルはトップレベルに以下を持ちます。

- `schemaVersion`: 整数（初版は `1`）。アプリが解釈できる版より新しい JSON は無視し、既存キャッシュで続行します。
- `updatedAt`: ISO 8601 UTC 日時（例：`2026-11-19T00:00:00Z`）。データ本体に差分があるときのみ更新されます。
