# storage マスターデータ（🐿️簡単収納管理）

🐿️簡単収納管理（EasyRoomStorage）が参照する、見取り図（間取り）SVGテンプレートの追加配信用マスターデータです。

## ファイル一覧

| ファイル | 内容 | 更新方針 |
| --- | --- | --- |
| `templates.json` | 定番間取り・収納特化レイアウトのSVGテンプレート定義 | 手動PRによりテキストSVGテンプレートを追加・更新 |

## SVGテンプレート仕様・セキュリティ制約

1. **テキスト資産のみ**：バイナリ画像（Base64埋め込み画像や外部URL参照 `<image>`）は一切含めません。
2. **スクリプト禁止**：`<script>` タグや `on*` イベントハンドラを含むSVGはアプリ側で拒否されます。
3. **標準デザイン規約**：
   - `viewBox="0 0 800 560"`
   - 標準アースカラー配色：背景 `#FBF8F3`（または `#FDF9F2`）、壁線 `#5C4B3B`（または `#5C4433`）、文字 `#6E5D4F`
   - 使用タグ：`<svg>`, `<rect>`, `<line>`, `<circle>`, `<path>`, `<g>`, `<text>`
